# SOC-Home-Lab-Deployment-with-Wazuh
Project Overview
This project focuses on the hands-on engineering, deployment, and operational testing of a virtualized Security Operations Center (SOC) environment designed to mirror real-world enterprise defensive workflows. Built to bridge the gap between network security fundamentals and active threat detection, the lab establishes a complete security telemetry pipeline using Wazuh SIEM as the central monitoring engine, Kali Linux for adversary emulation, and Metasploitable2 as a vulnerable Linux target.
